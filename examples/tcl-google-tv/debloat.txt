# TCL Google TV — ponto de partida para a sala.
# Adaptado da lista examples/tcl-google-tv-g07 de tv-home (TCL G07, Android 11).
# Não é um inventário da sua TCL 75" QD Mini LED. Leia antes de aplicar.
# Pacote que não existir na TV gera um erro e o script segue para o próximo.
#
# Aplicar:  tools/disable.sh examples/tcl-google-tv/debloat.txt
# Desfazer: tools/restore.sh examples/tcl-google-tv/debloat.txt
#
# Só desabilita para o usuário 0. Não desinstala.
# Comente a linha de qualquer coisa que você use.
#
# NÃO coloque estes pacotes aqui (o script recusa). O install desliga e o restore liga:
#   com.google.android.tungsten.setupwraith
#   com.google.android.apps.tv.launcherx
#   com.google.android.tvlauncher
# Também não desabilite Play Store, GMS, Configurações, TV ao vivo, Netflix, YouTube,
# Globoplay, Prime Video, Disney+, Stremio, Plex ou Jellyfin.
